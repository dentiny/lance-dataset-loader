# Synthetic Lance fixtures

This directory contains four tiny version-1 Lance datasets used by the feature examples. See [../README.md](../README.md) for schemas, row counts and usage, and `catalog.json` for machine-readable metadata.

The data was generated locally by `../generate_data.py`. Text and integer token IDs are synthetic; no external data or model downloads are needed. Preserve each complete `.lance/` directory, including its version manifests.
